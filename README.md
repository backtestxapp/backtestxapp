## 🚀 What is BacktestX?

BacktestX is a powerful trading backtesting platform that lets traders test, refine, and compete with their strategies — all in one place.

- 📊 **Historical Data** — Access years of market data across multiple assets
- 🤖 **Algo Trading** — Build and test automated strategies without code
- 🏆 **Leaderboard** — Rank your strategy against thousands of traders
- ⚔️ **Battle Mode** — Challenge other traders head-to-head
- 🌐 **Community** — Share, discuss, and learn from top strategies
